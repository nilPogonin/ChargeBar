# Проверка сборки 1.0.0

- Успешная кросс-сборка Windows x64, GUI subsystem, CGO выключен.
- `go vet ./...` для Windows x64 без замечаний.
- `go test -race -cover ./internal/battery`: все тесты проходят; покрытие логики
  протоколов/состояний около 82%. Это не покрытие Win32-интерфейса и USB-транспорта.
- Фаззинг парсеров: 594 045 входов за 3 секунды, без паник и недопустимых процентов.
- Проверяются реальные примеры формата Nordic, команды чтения и контрольные суммы,
  ошибочные заголовки/проценты, эхо, соседние HID-коллекции, сон/отключение,
  срок хранения старого значения и повторные уведомления.
- При упаковке проверены PE-заголовок x64 GUI, SHA-256 и целостность ZIP.

Ограничения проверки: среда сборки — macOS. Программа ещё не запускалась на Windows;
визуальный вид, Win32-вызовы, аппаратный обмен, реальное потребление ресурсов и
совместимость конкретных прошивок ATK Phantom / V9 Pro не проверены.
Режим `--demo` предназначен для проверки интерфейса без устройств на Windows.
