# ChargeBar

Заряд **ATK Phantom** и **MCHOSE V9 Pro** в системном трее Windows.
Один EXE, без установки Python, .NET и фирменных приложений.

## Скачать

**[⬇ Скачать ChargeBar.exe для Windows x64](https://github.com/nilPogonin/ChargeBar/releases/latest/download/ChargeBar.exe)**

[Все релизы и ZIP-архив](https://github.com/nilPogonin/ChargeBar/releases/latest)

Первая экспериментальная версия: сборка и тесты протоколов выполнены,
но работа интерфейса и обмен с физическими устройствами ещё не подтверждены.

## Запуск

1. Скачай `ChargeBar.exe` и помести в постоянную папку.
2. Запусти EXE. Установка и права администратора не нужны.
3. Если значки спрятаны под `^`, перетащи их к часам.
4. Левая кнопка — окно устройств, правая — настройки.

Нужны Windows 10/11 x64, обычный ПК с Intel или AMD.

## Возможности

- Отдельный значок с процентом для мыши и наушников.
- Дополнительный компактный виджет над панелью задач.
- Автозапуск и уведомления при низком заряде.
- Опрос раз в 15, 30 или 60 секунд.
- Обновление при переподключении и выходе Windows из сна.
- Скрытие виджета и отсрочка уведомлений в полноэкранных приложениях.
- Локальная диагностика без автоматической отправки данных.

Длинная линия под числом обозначает мышь, короткая — наушники.
Синий цвет означает зарядку, красный — низкий заряд. Серое `~83%` —
последнее значение спящей мыши. `—` означает, что заряд прочитать не удалось.

## Подключения

| Устройство | Реализация | Статус проверки |
| --- | --- | --- |
| ATK Phantom | USB / приёмники 2,4 ГГц, ATK Classic и Nordic 54 | На устройстве ещё не проверено |
| MCHOSE V9 Pro | Приёмник `291D:385D`, HID `FF90:0001` | На устройстве ещё не проверено |
| V9 Pro по кабелю | Отдельный протокол заряда не подтверждён | Возможен `—` вместо процента |

Приложение рассчитано на одну подключённую мышь ATK. Некоторые приёмники общие
для семейства ATK. Bluetooth не используется. Программа не меняет DPI,
настройки звука, прошивки и параметры устройств.

## Если заряд не появился

Включи устройство, пошевели мышью и нажми «Обновить сейчас». На время проверки
закрой ATK HUB/MCHOSE HUB и вкладку веб-драйвера, чтобы избежать одновременного
опроса одного интерфейса.

Правая кнопка по значку → **«Сохранить диагностику…»**. После свежего опроса
откроется TXT. Приложи его к issue вместе с моделью, способом подключения
и версией прошивки. Отчёт содержит USB-метаданные и пакеты заряда;
серийные номера и полные пути устройств не записываются.

Настройки и отчёты сохраняются в `%APPDATA%\ChargeBar`.

## Сборка из исходников

Go 1.24 или новее; сторонних Go-модулей нет.

```powershell
go test ./internal/battery
go build -trimpath -ldflags "-H=windowsgui -s -w" -o dist/ChargeBar.exe ./cmd/chargebar
```

Кросс-сборка с macOS/Linux: `GOOS=windows GOARCH=amd64 CGO_ENABLED=0`.
`ChargeBar.exe --demo` показывает демонстрационные значения без обращения к HID.

GitHub Actions тестирует код, собирает EXE и автоматически создаёт первый релиз
`v1.0.0` при первой загрузке в `main`. Следующие релизы создаются по тегам `v*`.
